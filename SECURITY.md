# Security Policy

## Supported versions
Only the [latest release](https://github.com/cosmichackerx/LinkXOrbit/releases/latest) receives fixes.

## Reporting a vulnerability
Please **do not** open a public issue. Report it privately through [GitHub Security Advisories](https://github.com/cosmichackerx/LinkXOrbit/security/advisories/new). You should get a reply within a few days.

## How your data is handled
LinkXOrbit stores your LinkedIn session cookies, settings and counters only on your PC, in the Electron `userData` folder. It does not send them to any server other than LinkedIn itself.
