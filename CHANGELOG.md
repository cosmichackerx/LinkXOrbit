# Changelog

All notable changes to LinkXOrbit are documented here.

## [1.2.1]
### Fixed
- Unfollow: the confirmation popup is now found and confirmed even when LinkedIn renders it inside a shadow DOM.
- Unfollow: auto-scroll now works with LinkedIn's inner list container, so the search continues past the first screen.

## [1.2.0]
### Added
- Redesigned interface: sidebar navigation, getting-started checklist, run panel with progress bar, stat tiles.
- Timestamped, color-coded activity log with copy and clear.
- Settings with mode cards, inline validation, run-time estimate and an unsaved-changes bar (Ctrl+S).
- Confirmation dialogs and notifications.
- New app logo and Windows icons.

## [1.1.0]
### Added
- Settings screen with saved mode: grow network or unfollow.
- Auto-stop when LinkedIn's weekly invitation limit is reached.
